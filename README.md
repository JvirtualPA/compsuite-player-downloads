# CompSuite Player beta downloads

Official desktop beta installers for CompSuite Player. Visit [CompSuite](https://www.compsuite.uk) for festival management and beta access enquiries.

This repository distributes installers only. Version 0.1.2 includes offline music preparation, check-in and performance modes, Space/Escape controls, track volume levelling and confirmed local festival removal.

Mac: Apple silicon (M1 or newer), ZIP. Windows: 64-bit installer. These beta installers are unsigned. Intel Mac builds are not available yet.

Downloading does not enable festival access or create a subscription. Approved organisations can use Player free during beta. Ask hello@compsuite.uk to enable Player, then sign in with your CompSuite organisation administrator account. The practice programme works without sign-in.

Prepare music separately on each computer while online, review the saved running order, and test playback and the audio output before a live festival. Existing website music uploads and exports continue without the Player add-on.

To update, quit Player, unzip the Mac app or run the Windows installer, then open the updated app. Prepared festivals remain saved. After your festival, select its saved playlist and choose Remove festival from this computer. Original web uploads and other devices are unchanged.

For help or beta feedback, contact hello@compsuite.uk.
